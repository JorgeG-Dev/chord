## [1.0.0] - 2026-07-03

1.0.0. is the first major release of Chord, and also the first release in general.
It includes the basic operations needed for a Chord workspace.

### Added

- Support for `init` command.
- Support for `sync` command.
- Support for `update` command.
- Support for `topdir` command.
- Support for `forall` command.
- Support for `status` command.
